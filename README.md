# 背面有座城 · 比赛独立篇（Demo）

纯前端 H5 单机游戏，无构建步骤、无外部依赖。前两章构成一个完整可玩的比赛独立篇（约 40–60 分钟）。

## 启动

推荐在项目根目录（含 `index.html`）启动一个静态服务器：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

也可直接用浏览器打开 `index.html`（现代浏览器允许 ES Module 通过 file:// 加载；若被拦截，请使用上面的静态服务器方式）。

## 操作

- 鼠标 / 触屏：点卡 → 点目标格完成放置或交换；右侧面板可查看卡片正反面、居民路线，并执行旋转、翻面、收放、迁居、安排值守。
- 键盘：方向键选格、`Enter` 选择、`R` 旋转、`F` 翻面、`Ctrl+Z` 撤销。
- 每日默认 4 手，翻面 / 旋转 / 换位 / 收放 / 迁居 / 换约定各耗 1 手；规划期内可无限撤销 / 重做，确认后进入夜间记录。
- 右侧顶栏可打开约定抽屉、档案抽屉与说明；确认一天固定在右下角。

## 目录

```
index.html          页面入口
css/style.css       全部样式（横屏布局、像素化卡面、纸面面板）
js/data.js          街区卡 / 居民 / 约定 / 章节 / 成就数据
js/engine.js        规则引擎（连通、供电、床位、服务、结算、存档状态）
js/story.js         开场、事件、章节收束、结局文本
js/ui.js            界面渲染与交互流程
js/main.js          启动、本地存档、设置
assets/cards/       20 张 200×200 像素街区卡面（正 / 背）
assets/residents/   6 张居民立绘
assets/ui/          封面、桌面、约定卡
package.json        仅声明 type: module
```

## 存档

自动保存在浏览器 localStorage（键 `backcity.save.v1`），档案抽屉内提供 3 个手动存档位与存档导入 / 导出。
